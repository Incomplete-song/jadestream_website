# AI 生图原理与 ComfyUI 工作流笔记

## 一、AI 生图的本质：不断去噪

AI 生图实际上是**不断去噪的过程**：

1. 去噪模型在得到生图要求后，**随机生成一张噪声图**（这个随机根据种子 seed 来）
2. 通过提示词**不断地去噪**
3. 最终得到图片

---

## 二、工作流各区块及专业名词的意义

### 文本理解模型

| 项目 | 说明 |
|------|------|
| `qwen3-4b-z-image-turbo-abliteratedv1-q4_k_m.gguf` | 选择具体的**文本理解模型** |
| `stable_diffusion` | 指定 CLIP 模型的类型或加载模式 |
| `GGUF` | 一种专门为在普通电脑上（尤其是显存不够的电脑）运行大语言模型和 AI 绘图模型而设计的**压缩文件格式** |

### 去噪主模型

| 项目 | 说明 |
|------|------|
| `z-image-turbo-q4_k_m.gguf` | **去噪模型**（根据提示词生图的模型） |

### 空 Latent 图像

| 项目 | 说明 |
|------|------|
| 宽高 | 生成图像的**大小** |
| 批量大小 | **一次性生成的图片数量**，数量越多越占显存 |

### K 采样器

| 参数 | 说明 |
|------|------|
| 模型 | 来自**去噪主模型** |
| 正负面条件 | 来自不同的 **CLIP 文本编码** |
| Latent 图像 | 来自**空 Latent 图像** |
| 添加噪波 | `enable` 表示**加满噪点**（从 0 开始），让 AI 从“雪花屏”开始去噪。如果是**图生图**，这里通常设为 `disable`，因为原图本身已经包含了部分信息 |
| 随机种 | **相同的随机种 + 相同的提示词 + 相同的模型 = 生成完全一样的图片**。如果要固定一张图反复微调，就锁定这个数字；如果想每次都不一样，就设为随机 |
| 生成后控制 | 每次运行完随机种如何变化。`randomize` 表示每次运行完随机种都变化 |
| 步数 | 去噪几步后得到最终结果，一般 Turbo 模型经过特殊训练只需要 **8 步** |
| CFG | 表示模型有多“听”提示词的话，通常 SD1.5 模型 CFG 在 **7–9** 之间。**Turbo 模型的特性就是 CFG 必须设为 1.0**，如果调高，画面就会严重过曝、色彩崩坏 |
| 采样器名称 | 选择哪种数学算法来去除噪点，`euler`（欧拉）是最基础、最快、最常用的采样算法之一 |
| 调度器 | `simple` 代表均匀、简单地去噪。适合 **Turbo 模型** |
| 返回剩余噪波 | 是否保留未去噪完的“半成品”，`disable` 表示不保留。因为我们要的是最终画好的成品图，而不是半成品，所以关闭 |

### VAE 解码

| 项目 | 说明 |
|------|------|
| VAE 解码 | 把 AI 画图的复杂矩阵和抽象向量**解码成我们能看懂的图像** |

## 三、生成不同风格图片的方法

想生成不同风格的图片，需要：

1. **更换“去噪主模型”** ✅ 这是最好的办法
2. 添加 **LoRA**（小型的风格外挂插件）
